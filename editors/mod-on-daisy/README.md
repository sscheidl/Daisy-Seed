# Mod on Daisy Editor

Grafischer Editor für die Modulationsmatrix [Mod on Daisy](../../modules/mod-on-daisy/):
eine vollständig sichtbare **8×8-Rastermatrix** nach dem Vorbild von
MatrixBrute/MiniFreak, dazu die Parameter der Modulationsquellen. Die Verbindung zum
Daisy läuft über USB-MIDI.

**Status: Konzept (Phase 1).** Es gibt noch keinen Code. Die Umsetzung mit **JUCE**,
zunächst als Standalone-Anwendung für Windows, folgt in Phase 3. Eine VST3-Version für
Studio One soll später möglich bleiben.
