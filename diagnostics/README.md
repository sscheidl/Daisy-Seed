# Daisy Seed3 Hardware Diagnostic Suite ist umgezogen

Die Diagnose-Suite wird eigenstaendig in
[sscheidl/Daisy-Seed3-Desktop-Diagnostics](https://github.com/sscheidl/Daisy-Seed3-Desktop-Diagnostics)
entwickelt. Dort liegen Firmware, Windows-GUI, Protokoll, Simulator, Tests und Dokumentation.

[Binaerdateien: BIN/ELF und Windows-EXE](https://github.com/sscheidl/Daisy-Seed3-Desktop-Diagnostics/actions/workflows/diagnostics.yml)
stehen als Artefakte des letzten erfolgreichen Builds bereit, jeweils mit SHA-256.
Das Repository ist wie dieses privat; fuer Downloads ist Zugriff erforderlich.

Die Diagnose-Historie wurde uebernommen. Historische Staende bleiben auch hier in Git
und in den bisherigen PRs erhalten. Dieses Repository konzentriert sich auf das Toy Piano.
Hardwaretests der Diagnose sind weiterhin offen; die Ausgliederung flasht kein Geraet.
