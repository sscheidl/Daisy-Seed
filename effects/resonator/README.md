# Resonator — Effektprojekt

**Stand: geplant, kein Build.** Projekt-ID: `resonator-fx`.

Spätere Audioeingangs-Variante des [Physical-Modeling-Instruments](../../instruments/physical-modeling/).
Ein externes Audiosignal regt einen Resonanzkörper an. Nach dem Instrumentprototyp
werden Eingangspegel, Dry/Wet-Verhalten, Resonanzbegrenzung und Stabilität getestet.
Gemeinsamer DSP soll wiederverwendet werden; die Board-/I/O-Anwendung bleibt eigenständig.

Quellen und Vergleich: [Referenzen](../../docs/REFERENCES.md).
`make PROJECT=resonator-fx` meldet den noch fehlenden Implementierungsstand.
