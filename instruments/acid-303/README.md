# Acid 303

Monophone Stimme nach dem Vorbild TB-303: Säge oder Rechteck (DaisySP PolyBLEP),
DaisySP-`LadderFilter` mit Selbstoszillation (D4), Filterhüllkurve, Accent und
Slide. Header-only-Kern für das Produkt [Acid Seq](../../sequencers/acid-seq/) und
eigene Firmware `acid-303` zum Testen.
