Streichwurst 0.1.0 – User Manual

String machine with solo voices and ensemble effects for the Electro-Smith Seed3 Desktop Development Kit · Test build 1 · 1 November 2026 · built from main @ 0a29966 · manual revision 2 (English control app)

Streichwurst is a polyphonic string machine in the spirit of the Waldorf Streichfett: a fully polyphonic string section, eight solo voices, and an effects section with Animate, Ensemble, Phaser and Reverb. It is its own implementation built from documented research; it is not a copy of the original and does not claim to sound identical. The string section and the ensemble follow the documented structure of the original most closely; the soli, Animate, Phaser and Reverb are own designs.

1. Installing the firmware

  • Compare the checksum with SHA256SUMS.txt before flashing.
  • First time or recovery: hold BOOT, press RESET, release BOOT, then flash over DFU (Daisy Web Programmer or make PROJECT=streichwurst program-dfu).
  • Without the Seed buttons: hold S9 + S16 (and no other key) for 5 s, or use Firmware update … in the control app. All 16 LEDs light up and the bootloader waits for DFU without a time limit.
  • Recommended order: first test the FX image alone, then the instrument (“Modular FX first”).

3. How it sounds and is built

Strings  -> Animate -> Ensemble -> Phaser -> stereo  \
Soli (bypass the string effects) ------------------->  Balance -> Reverb -> Master -> limiter -> OUT
  • Strings: all 128 notes are available at the same time. Twelve free-running clocks (one per pitch class) are divided down into all octaves, like on classic string machines. Registration morphs from a dark, full sound to a thin, bright one; Octaves selects the base footage, both, or the upper octave. Crescendo and Release are the swell and fade times (about 0.6 ms to 4.4 s).
  • Soli: eight voices with a Tone morph (hollow square → saw → narrow pulse, darker → brighter), attack, release, sustain level, three sustain modes and tremolo. In Split mode the keys below the split key play the strings and the keys from the split key up play the soli; in Layer mode every key plays both.
  • Ensemble: three modes with 3, 5 and 3 modulated delay taps and three LFOs (0.32, 0.81 and 7.77 Hz). Switching the mode or the ensemble on/off cross-fades in 20 ms. As in the original, the ensemble makes the whole output louder or quieter depending on the mode (mode 1 is the densest).
  • Animate slowly moves the registration and adds a wandering band emphasis; Phaser sweeps the ensemble sum; Reverb works on the whole mix including the soli.
  • Balance in the middle plays both sections at full level; turning it to one side fades the other out.

4. Controls on the kit

The eight pots have three pages. S9 switches Main → Solo → FX; S9–S11 show the active page (a short blink after a change). After a page change, a preset, or a change from MIDI or the app, a pot does nothing until you turn it across the current value (soft takeover), so values never jump.

5. MIDI

  • Notes, velocity, pitch bend (±2 semitones by default), sustain pedal (CC64), All Notes Off (CC123) and All Sound Off (CC120). Pitch bend moves strings and soli together.
  • MIDI channel: omni by default; set 1–16 in the app (Global page). Changing it releases held notes.
  • The strings ignore velocity by default (Velocity (strings) = 0 %); the soli follow velocity fully.
  • CC1 (mod wheel) and aftertouch belong to the modulation matrix.

6. Control app and modulation matrix

  • Use the Mod on Daisy Editor 0.4.0 or newer (Windows app, VST3 plug-in, or the browser page editors/mod-on-daisy/web/index.html in Chrome/Edge). Close other programs that hold the MIDI port.
  • Connect selects the port. On connect the app reads the kit first; nothing is overwritten. The status line shows streichwurst 0.1.0 · SQ + Matrix.
  • Pages Strings, Solo, Keyboard, FX, Global hold every parameter. Pot moves on the kit appear in the app; Read from device reads everything again.
  • Matrix (top) switches to the 8 × 8 modulation matrix; Sound parameters switches back. Sources: LFO 1/2, Random, CV 1/2, mod wheel, channel and poly aftertouch. Targets: Registration, Animate, Phaser, Reverb, Balance, Solo Tone, Tremolo (±100 %) and Pitch (±1 semitone). At most eight active connections; an empty matrix leaves the sound unchanged.
  • Save patch … saves a .swpatch file with all parameters and the matrix. Load patch … shows what fits; only Send to device sends it. In the VST3 plug-in the patch is stored in the song.
  • Read counters shows diagnostics, e.g. callback peak (CPU) and free stack.
Editor 0.3.0 also works with this firmware, but shows the same functions with German labels (Tastatur, Klangparameter, Patch speichern / laden, Auf Gerät übertragen, Zähler lesen). The FX image shows only the FX page and no matrix.

9. Troubleshooting

ObservationCheck
No sound from MIDIMIDI channel on the Global page (0 = omni); USB port held by another program?
A pot does nothingSoft takeover: turn it across the current value. Check the page (S9 LEDs).
Strings only, no solo (or the reverse)Balance (VR4 on Main); Layer/Split and split key (S14, VR7 on Solo).
Volume jumps when switching the ensembleExpected: the ensemble mode sets the overall level, as in the original.
Hanging notesS16 (panic) or CC123; report the situation.
Crackles, drop-outsNote the setting and read the counters in the app (callback peak, overruns); report them.
The app shows no Streichwurst pagesEditor 0.3.0 or newer is needed.
