# Provenance

Grain Cloud is original code for this repository (MIT).

* **Design source:** the engine design and rules R1 to R9 of the owner's private design
  documents. Those documents took only general principles from a static analysis of a
  commercial granular synthesizer.
* **Not in this repository:** no tables, constants, data layouts, code or disassembly of any
  other product. All values here are own choices. No output of the analysis is reproduced.
* **Techniques used:** linear interpolation, Hann and Tukey-style windows, equal-power panning,
  a linear congruential generator and a sum of two uniform values, all general textbook methods.
* **Reused repository code:** Mod on Daisy (matrix), the SPSC queue and triple buffer of Step Seq,
  `common/dsp/fastmath.h`, and the FX contract 1.0 as the effect interface.
* **Test signals** are generated by the tests.
